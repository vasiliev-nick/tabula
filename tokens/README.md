# Токены

Здесь будут токены Tabula в формате [W3C Design Tokens (DTCG)](https://www.designtokens.org/).
Из них Style Dictionary собирает CSS-переменные в `css/`.

Три уровня:

1. **Базовые значения** (`base/`): палитра, шкала размеров, длительности.
2. **Смысловые роли** (`semantic/`): «бумага», «чернила», «ошибка», «поле».
3. **Токены компонентов** (`component/`): «кнопка, основная, фон».

Компоненты ссылаются только на смысловые роли, а не на базовые значения.
