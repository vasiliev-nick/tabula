# Tabula

Визуальный язык для книг, статей, учебников, сайтов, приложений и интерфейса операционной системы.

*Tabula* — восковая табличка, на которой писали и стирали. *Tabula rasa* — чистый лист.

## Направление

С 3 ноября 2026 система строится в духе Miro:

- светлый фон — почти белый, с лёгкой бежевостью, как старая бумага;
- заголовки — красивая антиква с засечками, остальной текст — мягкий гротеск;
- интерфейс тихий, а цвет живёт в контенте: акценты сочные, яркие, не боятся быть мультяшными;
- иерархия через размер и воздух, заливки вместо обводок.

Систему проверяем на реальных кейсах. Первый — приложение «Карта здоровья» (`explorations/health-miro.html`).

## Устройство

| Папка | Что внутри |
| --- | --- |
| `tokens/` | Токены в формате DTCG: цвет, типографика, сетка, форма, глубина, движение |
| `css/` | Собранные CSS-переменные и стили компонентов |
| `site/` | Сайт документации системы |
| `explorations/` | Поиски и черновики, которые помогли принять решения |

## Состояние

Поиск направления на кейсе «Карта здоровья». Решено: имя Tabula. Ранние поиски (бумага, рамки, прямые углы) лежат в `explorations/` для истории.
