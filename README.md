# Tabula

Визуальный язык для книг, статей, учебников, сайтов, приложений и интерфейса операционной системы.

*Tabula* — восковая табличка, на которой писали и стирали. *Tabula rasa* — чистый лист.

## Принципы

1. **Чистота.** Каждый элемент обязан своим присутствием смыслу.
2. **Честность материала.** Бумага, чернила, линия, калька. Стекло и размытие допустимы, когда показывают настоящий слой поверх другого.
3. **Дискретность.** Чёткие границы, прямые углы, модули на сетке. Экран делится на панели.
4. **Лёгкость.** Воздух, тонкие линии, спокойный ритм.
5. **Вне времени.** Опора на традицию книги и надписи, а не на тренды.

Главная мера качества — удовольствие от чтения.

## Устройство

| Папка | Что внутри |
| --- | --- |
| `tokens/` | Токены в формате DTCG: цвет, типографика, сетка, форма, глубина, движение |
| `css/` | Собранные CSS-переменные и стили компонентов |
| `site/` | Сайт документации системы |
| `explorations/` | Поиски и черновики, которые помогли принять решения |

## Состояние

Этап 0: характер и грамматика. Решения: имя Tabula, прямые углы, зернистая бумага, панели как основная единица компоновки.
